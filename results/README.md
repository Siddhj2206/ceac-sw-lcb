## Rebuilding

```bash
uv run python run_experiments.py
uv run python closure_study.py
uv run python shock_study.py
uv run python attrib_breaks.py
uv run python dump_series.py
uv run python analyse.py
uv run python plots.py
```

`analyse.py` must run after the CSV-producing scripts. `plots.py` needs
`series.csv` for Figure 4 and skips it if the file is missing.
